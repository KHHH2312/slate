# Changelog

## 1.6.0 — 2026-10-30

- Note templates: blank, meeting notes, daily note and reading note, with markdown bodies and tags.
- Browser proof grows to 39 checks.

## 1.5.0 — 2026-10-30

- Tag entry suggests tags already on the desk.
- Clicking a note tag filters the desk; All notes restores it.
- Browser proof grows to 36 checks.

## 1.4.0 — 2026-10-30

- Move the open note between notebooks with a picker in its meta strip.
- Browser proof grows to 34 checks.

## 1.3.0 — 2026-10-30

- Export a note as a self-contained, paper-styled HTML page with escaped markup.
- Suite grows to 101 checks; browser proof grows to 32.

## 1.2.0 — 2026-10-30

- Task lists are clickable in the preview; toggling updates the markdown and autosaves.
- Suite grows to 98 checks; browser proof grows to 31.

## 1.1.0 — 2026-10-30

- Insert, paste or drop PNG, JPEG and WebP images into a note.
- Images are validated locally (type, 5 MB cap, magic bytes) and stored in the app data folder.
- Model/API suite grows to 97 checks; the browser proof grows to 29.

## 1.0.0 — 2026-10-30

- First public release of Slate.
